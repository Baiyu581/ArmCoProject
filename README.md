# Collaborative 5-6 DOF Robot Arm Project

Custom 3D-printed desktop pick-and-place robot arm built by Arturo Rodriguez (Software & Controls Engineer) and Christopher Amaya (Mechanical & Embedded Engineer).

## Project Goals
- 5–6 degrees of freedom
- Custom 3D-printed structure
- Arduino/ESP32 firmware
- Python high-level control + Inverse Kinematics
- Phone-accessible web dashboard (Streamlit)
- Vision-based object detection & pickup
- Move sequence recorder/playback

## Roles
- **Arturo** – Software architecture, Python control, IK solver, Streamlit dashboard, OpenCV vision, integration
- **Chris** – 3D modeling & printing, mechanical assembly, Arduino firmware, wiring & calibration
